# 落地手册（分段）

这份手册对应你要求的路线：`Electron 桌面端 + FastAPI 引擎 + Postgres/pgvector`。

## 第1段：准备环境（Ubuntu）
1. 安装基础包：
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git build-essential jq python3 python3-venv python3-pip
```
2. 安装 Docker（若未安装）：
```bash
sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker $USER
```
3. 重新登录后验证：
```bash
docker version
```

## 第2段：启动数据库（pgvector）
1. 进入项目根目录。
2. 启动数据库：
```bash
docker compose -f infra/docker-compose.yml up -d
```
3. 验证扩展：
```bash
docker exec -it writerbook_pg psql -U postgres -d novel_db -c "\dx"
```
看到 `vector` 即成功。

## 第3段：启动引擎
1. 一键启动（Linux）：
```bash
bash dev-engine.sh
```
2. 或手动启动：
```bash
cd engine
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 17777
```

## 第4段：初始化数据库表
```bash
curl -X POST http://127.0.0.1:17777/v1/system/db/init
curl http://127.0.0.1:17777/v1/system/info | jq
```
`tables` 全为 `true` 表示初始化完成。

## 第5段：创建书并导入 TXT（异步 Job）
1. 创建书：
```bash
curl -X POST http://127.0.0.1:17777/v1/books \
  -H "Content-Type: application/json" \
  -d '{"title":"测试书","author":"me"}'
```
记下 `book_id`。

2. 提交导入任务：
```bash
curl -X POST http://127.0.0.1:17777/v1/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "capability_id":"ingest.book.v1",
    "input":{
      "book_id":"替换为book_id",
      "path":"/home/你的用户名/novels/book.txt",
      "encoding":"utf-8",
      "chunk_size":900,
      "overlap":120
    }
  }'
```
记下 `job_id`。

3. 查询任务状态：
```bash
curl http://127.0.0.1:17777/v1/jobs/替换为job_id | jq
```

4. 订阅实时进度（SSE）：
```bash
curl -N "http://127.0.0.1:17777/v1/events?job_id=替换为job_id"
```

## 第6段：检索
```bash
curl "http://127.0.0.1:17777/v1/search/chunks?q=主角&book_id=替换为book_id&top_k=20" | jq
```
混合检索（向量+关键词）：
```bash
curl "http://127.0.0.1:17777/v1/search/chunks?q=主角觉醒&book_id=替换为book_id&top_k=20&hybrid=true&vector_weight=0.7&keyword_weight=0.3" | jq
```

## 第6.5段：Ledger Apply（staging 应用到账本）
1. 创建一条 `skill_run`（联调用）：
```bash
curl -X POST http://127.0.0.1:17777/v1/skill_runs \
  -H "Content-Type: application/json" \
  -d '{
    "book_id":"替换book_id",
    "skill_name":"EXTRACT_CHARACTERS_V1",
    "schema_ver":1,
    "output":{
      "items":[
        {
          "name":"林烬",
          "aliases":["阿烬"],
          "role":"protagonist",
          "facts":{"traits":["隐忍"],"skills":["刀术"],"motivation":"复仇"},
          "evidence":[{"chunk_id":"替换真实chunk_id"}]
        }
      ]
    }
  }'
```
2. 应用到 ledger：
```bash
curl -X POST http://127.0.0.1:17777/v1/books/替换book_id/ledger/apply \
  -H "Content-Type: application/json" \
  -d '{
    "skill_run_id":"替换skill_run_id",
    "apply_policy":{
      "characters":"upsert_safe",
      "timeline":"append_only",
      "world":"merge_by_key_needs_review",
      "plot_hooks":"append_only"
    }
  }' | jq
```

## 第6.8段：结构模板库（Structure Template Library）
1. 创建 profile：
```bash
curl -X POST http://127.0.0.1:17777/v1/profiles \
  -H "Content-Type: application/json" \
  -d '{"name":"玄幻男频-热血","note":"模板测试"}' | jq
```
2. 提交结构节拍抽取 Job：
```bash
curl -X POST http://127.0.0.1:17777/v1/books/替换book_id/extract/structure_beats \
  -H "Content-Type: application/json" \
  -d '{
    "scope":{"chapter_range":[1,50]},
    "schema_ver":1
  }' | jq
```
3. 查看模板列表：
```bash
curl "http://127.0.0.1:17777/v1/profiles/替换profile_id/templates?level=chapter" | jq
```
4. 推荐模板：
```bash
curl -X POST "http://127.0.0.1:17777/v1/books/替换book_id/templates/recommend" \
  -H "Content-Type: application/json" \
  -d '{"profile_id":"替换profile_id","level":"chapter","top_k":5}' | jq
```
4.1 从 beats 生成模板（专用 API）：
```bash
curl -X POST "http://127.0.0.1:17777/v1/books/替换book_id/templates/generate_from_beats" \
  -H "Content-Type: application/json" \
  -d '{"skill_run_id":"替换skill_run_id","level":"chapter","name":"标准爽点章节结构","tags":["爽点","章节"]}' | jq
```
5. 记录模板使用反馈：
```bash
curl -X POST http://127.0.0.1:17777/v1/templates/替换template_id/use \
  -H "Content-Type: application/json" \
  -d '{"book_id":"替换book_id","usage_type":"outline","feedback":{"score":0.9,"note":"节奏稳定"}}' | jq
```

## 第6.9段：冲突强度自动调参（Tension）
1. 先准备章节版本（示例）：
```bash
docker exec -it writerbook_pg psql -U postgres -d novel_db -c "
INSERT INTO chapter_version(chapter_id, version, kind, text)
VALUES ('替换chapter_id', 1, 'draft', '这里放章节正文文本')
ON CONFLICT DO NOTHING;"
```
2. 发起评估 Job：
```bash
curl -X POST http://127.0.0.1:17777/v1/chapters/替换chapter_id/tension/eval \
  -H "Content-Type: application/json" \
  -d '{"chapter_version_id":"替换chapter_version_id","input_mode":"draft","schema_ver":1}' | jq
```
3. 用 skill_run 应用 patch（先改细纲节点 summary）：
```bash
curl -X POST http://127.0.0.1:17777/v1/chapters/替换chapter_id/tension/apply \
  -H "Content-Type: application/json" \
  -d '{"skill_run_id":"替换skill_run_id","apply_target":"outline_detail","mode":"staging_then_apply"}' | jq
```
4. 应用后会生成新的 chapter 细纲版本（`outline.scope=chapter`，`version+1`）。

## 第6.10段：爽点密度/冲突强度参数控制器
1. 生成控制计划（滑块参数）：
```bash
curl -X POST http://127.0.0.1:17777/v1/chapters/替换chapter_id/tension/control_plan \
  -H "Content-Type: application/json" \
  -d '{
    "outline_id": null,
    "targets": {
      "conflict_strength": 0.72,
      "stakes": 0.65,
      "cost": 0.60,
      "pace": 0.62,
      "reversal": 0.55,
      "hook": 0.60
    },
    "style": {
      "face_slap_density": 0.18,
      "upgrade_density": 0.14
    },
    "schema_ver": 1
  }' | jq
```
2. 任务完成后取 `skill_run_id`，调用 `/tension/apply` 应用补丁即可。

## 第6.11段：机制库预览（Mechanics Preview）
先预览机制补丁，再决定是否应用：
```bash
curl -X POST http://127.0.0.1:17777/v1/chapters/替换chapter_id/mechanics/preview \
  -H "Content-Type: application/json" \
  -d '{
    "outline_id": null,
    "mechanic": "face_slap",
    "selected_node_id": "N5",
    "strength": 0.7
  }' | jq
```
可选 mechanic：`face_slap / upgrade / reversal / timer / raise_stakes / cost_hardening / rescue / betrayal`

## 第6.12段：反抄袭相似度门控（SIMILARITY_GUARD）
```bash
curl -X POST http://127.0.0.1:17777/v1/chapters/替换chapter_id/similarity/guard \
  -H "Content-Type: application/json" \
  -d '{
    "chapter_version_id":"替换chapter_version_id",
    "vec_high":0.86,
    "vec_mid":0.80,
    "ngram_high":0.20,
    "ngram_mid":0.12
  }' | jq
```
完成后在 `skill_run.output.result` 查看：
- `risk_level`
- `max_vec_score`
- `max_ngram_overlap`
- `suggest.rewrite_mode`

## 第7段：启动桌面应用
1. 安装依赖：
```bash
npm install
```
2. 启动：
```bash
npm run dev
```
3. 进入应用后可使用原有写作/拆书 UI；后续建议接入上述引擎接口（Job/SSE/Search）。

## 第8段：故障排查
- 端口占用：
```bash
sudo fuser -k 17777/tcp
```
- 文件找不到：先验证路径
```bash
ls -lah /home/你的用户名/novels/book.txt
```
- 导入 `chunks_created=0`：检查文件是否空白
```bash
wc -c /home/你的用户名/novels/book.txt
head -n 5 /home/你的用户名/novels/book.txt | cat -A
```
