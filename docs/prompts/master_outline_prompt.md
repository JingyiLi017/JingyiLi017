# 总纲生成提示词参考（1.2）

## 目标
基于“定义创作简报”生成可执行的全书总纲，供后续卷纲/章纲/正文稳定迭代。

## 输入优先级
1. 创作简报（题材、主题、基调、受众、核心创意、世界设定）
2. 拆书库结构（仅结构节奏与冲突分布，不可复述原文）
3. 数据库上下文（卷信息、章节规模、既有节点）

## 必须遵守
- 仅借鉴结构规律，不得复制拆书文本。
- 不得照搬简报原句，需进行策划化重写。
- 生成结果必须可执行，能直接驱动卷纲与章纲。

## 输出要求
- `summary`：说明主线目标、阶段升级、终局承诺。
- `premise`：明确主角起点、推进机制、核心命题。
- `core_conflict`：描述主冲突双方与不可调和点。
- `phases`：按阶段给出目标与章节范围。
- `constraints`：包含防抄袭与连贯性约束。

## 质量门槛
- 每个阶段都要有“目标 + 阻力 + 回收/转折”。
- 不得出现空泛口号式描述（如仅罗列关键词）。
- 语言简体中文，表达可落地、可检查。
